# Curio 初筛标题展示规则

2026-10-06 用户对初筛标题的最新要求：

> 我觉得卖家写了1二等,可以借用没关系,有写磕碰的,修复的也可以在标题前面写出来,年代未知就不写没关系.

适用于初筛页、中文标题清单及导出的标题预览：

- 标题顺序：`【磕碰／修复等状态】年代（有则写）＋品牌＋卖家等级＋装饰与器型＋规格／组成`。
- 一等、二等可直接沿用卖家原文；页面统一注明来源于卖家描述。候选字段保存对应等级及证据，不将其转换为当前品相评分。
- 同一挂单出现不同等级时，显示“一／二等均有记载”，保留原文供分件核对。
- 未知年代省略。否定损伤陈述和包装破损不得成为商品损伤标题。
- 本修订覆盖旧 V2 规范中初筛标题必须等待等级核验的展示限制；正式核验状态仍单独保存。

- 年代展示补充：只有 Pfeiffer 时期标记按用户要求显示 1924–1934年；Knauf 是不同标记，不替换成 Pfeiffer 年代。明确卖家年份仍保留。价格独立显示金额、币种和交易类型。
